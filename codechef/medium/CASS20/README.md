## Problem

### BMI Calculator

Given the height (1.82 meter) and weight (72 kg) of the Chef, calculate his BMI (Body Mass Index).

Formula to calculate the BMI:

## Solution

**Language:** c_cpp  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-24T14:50:59.652Z  

```c_cpp
#include <stdio.h>

int main() {
    float height = 1.82;
    float weight = 72;
    // Complete the code
    float bmi = weight / (height * height);
    printf("%f", bmi);
    return 0;
}

```
