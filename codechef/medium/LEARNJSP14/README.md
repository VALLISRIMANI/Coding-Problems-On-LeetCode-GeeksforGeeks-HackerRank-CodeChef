## Problem

### Inserting text Between Outputs

Listen

Remember that to print multiple values on the same line, we have to use a comma inside the console statement.

We can also use commas to separate text and numbers in a single console statement.

For example, check the below code

```
console.log("My favorite number is", 10);

```

The code will output:

```
// My favorite number is 10

```

### Task
- You have to output the text:

```
7 plus 3 equals 10

```

- Replace the underscores in the editor to get the above output.

## Solution

**Language:** JavaScript  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-29T14:04:00.331Z  

```js
// Replace the underscores in the editor as suggested on the left. 

console.log(7, "plus", 3, "equals", 7 + 3);


```
