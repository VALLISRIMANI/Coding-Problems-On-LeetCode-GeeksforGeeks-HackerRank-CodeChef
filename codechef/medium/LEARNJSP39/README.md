## Problem

### String length

Listen

We can use the  **`length`**  property to get the length of a `string`.
For eg.

```
var greeting = "hello";
console.log(greeting.length);
// output is 5

```

### Task

Write a program which does the following

- Create a variable txt and assign it the text NumeroTres
- Use the length property to output to the console the number of characters in txt

## Solution

**Language:** JavaScript  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-10-16T16:00:51.042Z  

```js
// Solution as follows

var txt = "NumeroTres";
var txtLen = txt.length;
console.log(txtLen);
```
