# Absolute Value

![Difficulty](https://img.shields.io/badge/Difficulty-Basic-red)

## Problem

You are given an interger  **n**, find the absolute value of the integer  **n**.

 **Examples:** 

```
Input: n = -32
Output: 32
Explanation:The absolute value of -32 is 32.

```

```
Input: n = 45
Output: 45
Explanation: The absolute value of 45 is 45 itself.
```

 **Constraints:** 
-106 ≤ n ≤ 106

## Solution

**Language:** Java  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-29T10:22:53.963Z  

```java
class Solution {
    public int absolute(int n) {
        // code here
        return Math.abs(n);
    }
}

```
