# Function With No Arguments

![Difficulty](https://img.shields.io/badge/Difficulty-Basic-red)

## Problem

This problem has no input. You need to write a function to be named as  **helloFunction().** The function should only prints Hello followed by a new line.

 **Examples:** 

```
Input: None
Output: Hello
Explanation: There is no input. The function prints Hello everytime.

```

## Solution

**Language:** Java  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-11-28T16:42:36.841Z  

```java
// Write a function named as helloFunction() below

class Solution {
    // code here
    void helloFunction() {
        System.out.println("Hello");
    }
}
```
